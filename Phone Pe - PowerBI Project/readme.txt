📊 PhonePe Transaction Analytics Dashboard

An interactive Power BI dashboard designed to analyze PhonePe transaction data through a business intelligence lens.
The dashboard enables users to explore transaction volume, transaction value, user behavior, payment status, age segments, service categories, and weekday versus weekend usage through dynamic visualizations and interactive filters.

📖 Project Overview

This project focuses on transforming transaction data into meaningful business insights using Power BI.
The dashboard provides a consolidated view of key performance indicators (KPIs), transaction trends, user demographics, service performance, and payment success rates.

🎯 Business Objectives

✔ Monitor overall transaction volume and transaction value
✔ Analyze transaction trends over time
✔ Understand payment success and failure rates
✔ Analyze user behavior across different age segments
✔ Compare transaction value across services
✔ Identify top users by transaction value
✔ Compare weekday and weekend transaction activity
